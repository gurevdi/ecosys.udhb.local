# Как выложить правки на ecosys.udhb.local

Код в этой папке **уже сделан и проверен локально**. На сайте заказчика его ещё нет, пока вы сами не зальёте на сервер по SSH.

После шагов ниже прод будет соответствовать чеклисту `Правки.txt` (пункты **1, 3–5, 7–19**). Пункты **2** и **6** в этой копии намеренно не делались.

Не копируйте на сервер файл `.env` из этой папки. Пароли и секреты только те, что уже лежат в `/opt/ecosys/.env` на сервере.

---

## Что нужно на вашем ПК

- эта папка с исходниками (корень, где лежат `apps`, `deploy`, `Правки.txt`);
- **Node.js 20+** и `npm` (для сборки фронта);
- **OpenSSH-клиент** (в Windows 10: «Параметры → Приложения → Дополнительные компоненты → Клиент OpenSSH»);
- SSH-доступ на сервер экосистемы (как вы уже заходите).

Сервер: каталог `/opt/ecosys`, API `systemd` `ecosys-api`, сайт отдаёт nginx, БД PostgreSQL `ecosys`.

---

## 1. Настроить SSH-алиас `ecosys`

Скрипт деплоя вызывает именно хост **`ecosys`**, не IP вручную.

Файл: `%USERPROFILE%\.ssh\config` (Windows) или `~/.ssh/config` (Linux/macOS):

```
Host ecosys
    HostName 94.137.47.86
    Port 35222
    User root
    IdentityFile ~/.ssh/id_ed25519
```

`IdentityFile` — путь к **вашему** ключу, которым вы реально входите. Если ключ другой — подставьте его.

Проверка:

```powershell
ssh ecosys "curl -s http://127.0.0.1/api/health"
```

Ожидается что-то вроде `{"ok":true,"service":"ecosys"...}`. Если спрашивает пароль/ключ или `Could not resolve hostname ecosys` — дальше не идите, сначала почините SSH.

## 2. Сверить миграции (обязательно до заливки)

На сервере не должно быть **более новых** миграций, которых нет в этой папке. Иначе заливка затрёт серверный код.

```powershell
ssh ecosys "ls /opt/ecosys/apps/api/prisma/migrations/"
dir apps\api\prisma\migrations
```

Команды запускайте из **корня этой папки**.

- Если на сервере есть папки миграций, которых нет локально — **остановитесь**, сначала снимите копию с сервера, потом разбирайтесь.
- Если локально есть `20260918120000_pravki_contracts`, а на сервере её нет — так и должно быть, её как раз накатит деплой.

---

## 3. Зависимости фронта (один раз)

Из корня этой папки:

```powershell
cd apps\web
npm install
cd ..\..
```

Если `node_modules` уже стоят и `npm run build` проходит — этот шаг можно пропустить.

---

## 4. Деплой одной командой

Из **корня этой папки**:

```powershell
powershell -ExecutionPolicy Bypass -File deploy/sync-server.ps1
```

Скрипт сам:

1. собирает фронт (`apps/web` → `dist`);
2. копирует на сервер API (`src`, `prisma`, `package.json`) и `apps/web/dist`;
3. на сервере: `npm install`, `prisma generate`, `prisma migrate deploy`, `seed`, `systemctl restart ecosys-api`;
4. проверяет health.

В конце должно быть **`=== deploy ok ===`** и JSON health.

`seed` на проде безопасен: отделы/папки/шапка управления/адресаты оплат создаются, **если их ещё нет**. Существующие договоры и пользователи не удаляются. Файл `.env` на сервере скрипт не перезаписывает.

---

## 5. Если скрипт упал

| Симптом | Что делать |
|---|---|
| `vite build failed` | `cd apps\web` → `npm install` → повторить деплой |
| `scp ... failed` / `Permission denied` | ключ и `User` в SSH config |
| `Could not resolve hostname ecosys` | шаг 1, файл config |
| `prisma migrate deploy` ошибка | **не** дропать БД. Пришлите полный вывод. На проде только `migrate deploy`, не `db push` |
| health не `ok` | `ssh ecosys "journalctl -u ecosys-api -n 80 --no-pager"` |

Повторный запуск того же скрипта после исправления — нормально.

## 6. Проверка, что прод совпадает с ТЗ

В браузере откройте **http://ecosys.udhb.local** (или как у вас заведено) и нажмите **Ctrl+F5** (не обычный F5).

Войдите своей рабочей учёткой.

### Настройки → вкладка «Договоры»

- **Шапки служебных записок** — бланк «Управление» и бланки отделов.
- **Справочник поставщиков** — имя обязательно; ИНН, телефон, комментарий.
- **Адресаты служебок на оплату** — по одному на строку (в seed, если список был пустой: Тыщенко, Матюха, Бузько, Дыц). Можно свои.
- **Импорт архива CSV** — разделитель `;`.

### Реестр «Договоры»

- Кнопки **Excel** и **CSV**.
- **Колонки**: № контракта, Заключён, Действует до, Поставщик, Оплаты и т.д. (запоминаются в браузере).
- Фильтры: поставщик; **год считать по** «заключение / оплата / карточка / любой».

### Карточка договора

- КП: комбо поставщика из справочника.
- СЗ: шапка, **Скачать DOCX**, после формирования — **Исправить** (не удаляет СЗ).
- На согласовании — **одна** кнопка **Согласовать** (руководитель и директор сразу).
- Заключение: «действует до» сравнивается только с датой заключения (календарный день, Омск). `createdAt` и даты подписей СЗ не участвуют.
- Исполнитель: «не выбран» + ручной ввод.
- Ошибки/успех — **toast справа снизу**, красная полоса этапа сверху остаётся.
- Исполнение: **Фактическая дата поставки**; ориентир приёмки = факт + N дней (по умолчанию 10).
- Блок **Оплаты** (адресат, сумма, дата, файл служебки).
- **Скачать все файлы** — ZIP.

### Что не искать

- пункт 2 — пропуск;
- пункт 6 — ключевая ставка ЦБ в этой копии не добавлялась.

### Техконтроль с сервера

```powershell
ssh ecosys "ls /opt/ecosys/apps/api/prisma/migrations/ | findstr pravki"
ssh ecosys "curl -s http://127.0.0.1/api/health"
ssh ecosys "systemctl is-active ecosys-api"
```

Должны быть папка `20260918120000_pravki_contracts`, health ok, сервис `active`.

## 7. Если деплоите не с Windows

Тот же смысл, другими командами. Сначала `npm run build` в `apps/web`, затем:

```bash
scp -r apps/api/prisma apps/api/src ecosys:/opt/ecosys/apps/api/
scp apps/api/package.json apps/api/package-lock.json ecosys:/opt/ecosys/apps/api/
scp -r apps/web/dist ecosys:/opt/ecosys/apps/web/
ssh ecosys 'set -a && . /opt/ecosys/.env && set +a && cd /opt/ecosys/apps/api && npm install --omit=dev && npx prisma generate && npx prisma migrate deploy && npm run seed && systemctl restart ecosys-api && sleep 2 && curl -sf http://127.0.0.1/api/health'
```

Порт и ключ возьмутся из `Host ecosys` в SSH config.

## Кратко

1. SSH `ecosys` отвечает, health живой.  
2. Миграции сервера не новее этой папки.  
3. `deploy/sync-server.ps1` → `deploy ok`.  
4. На сайте **Ctrl+F5**, пройти настройки и одну живую карточку по списку выше.

Пока шаг 3 не выполнен, http://ecosys.udhb.local будет старой версией — это ожидаемо.
